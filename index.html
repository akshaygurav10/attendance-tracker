    Import from Team

    Import the latest JSON file shared by your team admin to sync your data.

    💡 How to share in Teams:
    1. Click "Download & Share" to get the JSON file
    2. Go to your Teams channel → Files tab
    3. Upload the downloaded file to the shared folder
    4. Team members can then "Import from Team" using that file
